### 임베디드 시스템 기본
* 정의: 특정한 기능을 수행하기 위해 설계된 HW와 SW가 결합된 시스템
* 특징
    * 자원 제한
        * 저전력
        * 소형 메모리
        * 전용 CPU
    * 특수 목적 MCU(마이크로 컨트롤러) + 메모리로 구성

* <span class="hl-yellow">기능 3</span>
    1. <span class="hl-yellow">센싱(Sensing)</span>: 물리량을 전기 신호로 변환
        * 물리 세계
        * 센서 -> ADC(analog to digital)
    2. <span class="hl-yellow">판단(Processing)</span>: 알고리즘에 따라 결정 
        * 디지털 세계
        * MCU 알고리즘
    3. <span class="hl-yellow">제어(Actuation)</span>: 액추에이터로 물리적 동작 
        * 물리 세계
        * DAC(digital to analog)/GPIO -> 모터
    -> 3에서 다시 1로 (피드백)

* 4대 핵심 가치
    * 실시간성
        * Hard RT: 데드라인 위반 = 시스템 실패
        * Soft RT: 지연 시 성능 저하
    * 신뢰성: 무중단, 오류X
    * 저전력, 소형화
    * 비용 최적화

* PC와의 차이(큰 것 위주)
    * 설계 철학: 목적 최적화
    * OS: 보통 RTOS

### 임베디드 시스템 구성 요소
1. <span class="hl-yellow">HW 구성 요소</span>
    * Core Processing: MCU, DSP 등
    * Memory: RAM, ROM
    * 입출력 장치: 센서, 액추에이터, 통신 IF
        ex. UART, SPI, I2C 등
    * 기타: Power supply, ADC, DAC, 무선 통신 시스템

2. SW 구성 요소
    * 펌웨어: 하드웨어와 맞닿아 동작하는 SW
    * RTOS(real time OS)
    * 미들웨어: OS와 응용 SW 사이에서 공통 서비스(통신 프로토콜 스택, 파일시스템, GUI 라이브러리 등)를 제공하는 SW

### 임베디드 SW
* 구조
    * 응용 SW: 사용자 기능 구현
    * RTOS/미들웨어: 태스크 관리, 스케줄링, 통신
    * BSP/드라이버: HW를 직접 제어
    * HW: MCU, 센서, 액추에이터
