1. DB 필요성
    - 데이터: 현실 세계에서 수집한 것
    - 정보: 데이터를 의사결정에 활용하기 위해 처리한 것
    - 정보 시스템: 데이터를 입력으로 받아 저장해뒀다가, 정보를 만들어주는 수단
        
        → 데이터베이스: 데이터를 저장
        
2. DB 정의와 특징
    1. 정의
        1. 공유
        2. 통합
        3. 저장
        4. 운영
    2. 특징
        1. 실시간 접근
        2. 계속 변화
        3. 내용으로 참조
        4. 동시 공유
3. 데이터의 분류
    1. 형태
        1. 정형
        2. 반정형
        3. 비정형
    2. 특성
        1. 범주형
            - 순서형: 서열 있음
            - 명목형: 서열 없음
        2. 수치형
            - 이산형
            - 연속형
