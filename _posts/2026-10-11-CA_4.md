### 1. 조건부 연산

1. **조건부 분기**
    * <span class="hl-yellow">**`beq`**</span>**`rs1, rs2, Label`** (Branch if Equal): `rs1 == rs2` 이면 `Label`로 점프
    * <span class="c-red"><span class="hl-yellow">**`bne`**</span></span>**`rs1, rs2, Label`** (Branch if Not Equal): `rs1 != rs2` 이면 `Label`로 점프
    * **`blt rs1, rs2, Label`** (Branch if Less Than): `rs1 < rs2` 이면 `Label`로 점프
    * **`bge rs1, rs2, Label`** (Branch if Greater or Equal): `rs1 >= rs2` 이면 `Label`로 점프

2. **부호 있는 비교 vs 부호 없는 비교**
    * **부호 있음 (Signed)**: `blt`, `bge` (음수와 양수를 구분하여 크기 비교)
    * **부호 없음 (Unsigned)**: `bltu`, `bgeu` (모든 비트를 양수로 간주하여 크기 비교)
    * **예시**: `x22 = 0xFFFFFFFF` (-1 또는 4,294,967,295), `x23 = 0x00000001` (+1)
        * `blt x22, x23, Label` → 부호 있음: -1 < +1 이므로 **참 (점프)**
        * `bltu x22, x23, Label` → 부호 없음: 4,294,967,295 > +1 이므로 **거짓 (점프X)**

3. **C 언어 제어 구문 변환 패턴**
    * **`if-else` 문**: 조건의 **반대 조건**을 검사하여 `Else` 레이블로 점프하고, `Then` 블록 끝에는 무조건 점프(`beq x0, x0, Exit`)
    * **`while` 루프**:
        1. 오프셋 계산(`slli`)
        2. 메모리 로드(`ld`)
        3. 탈출 조건 검사(`bne`)
        4. 인덱스 증가(`addi`)
        5. 루프 시작점으로 무조건 점프 (`beq x0, x0, Loop`)

4. **기본 블록**
    * 시작점 외에는 진입X, 끝점 외에는 분기X인 연속된 명령어 시퀀스
    * 컴파일러 최적화 및 하드웨어 실행 가속의 기본 단위

### 2. 프로시저(함수) 호출 메커니즘

1. <span class="hl-yellow">**프로시저 호출 6단계 절차**</span>
    1. 매개변수를 레지스터 **`x10 ~ x17`**에 배치
    2. 프로시저로 제어권 전달 (**`jal`** **= jump and link**)
    3. 프로시저 실행에 필요한 저장 공간(스택) 확보
    4. 프로시저 연산 수행
    5. 호출한 함수를 위해 결과값을 레지스터 **`x10 ~ x17`**에 저장
    6. 호출된 위치로 복귀 (**`jalr x0, 0(x1)`**, 복귀 위치: x1)

2. **핵심 명령어**
    * **`jal x1, ProcedureLabel`** (Jump and Link):
        * 다음 명령어 주소(`PC + 4`, 모든 명령어가 32bits = 4bytes니까)를 반환 주소 레지스터 **`x1 (ra)`**에 저장
        * 두 번째 피연산자에 해당하는 레이블로 점프
    * **`jalr x0, 0(x1)`** (Jump and Link Register):
        * `rd=x0`이므로 반환 주소를 저장하지 않음 = 다음 명령어 주소 그냥 버림
        * 레지스터 **`x1`**에 저장된 주소로 복귀 점프

3. **레지스터 보존 규약**
    * <span class="hl-yellow">**임시 레지스터**</span>**(`x5~x7`, `x28~x31`)**: 호출된 함수가 값 보존하지X
    * <span class="hl-yellow">**저장 레지스터**</span>**(`x8~x9`, `x18~x27`)**: 호출된 함수가 사용하기 전 스택에 저장했다가 원상 복구해야(값 보존 필수)

4. **말단(Leaf) vs 비말단(Non-Leaf) 프로시저**
    * **말단(Leaf) 프로시저**: 내부에서 다른 함수를 부르지 않는 함수

        ```c
        long long int leaf_example (long long int g, long long int h, long long int i, long long int j) {
            long long int f;
            f = (g + h) - (i + j);
            return f;
        }
        ```

        ```nasm
        leaf_example:
            ; 1. [스택 공간 확보] 8바이트 레지스터 3개(x5, x6, x20)를 저장하기 위해 24바이트 감축
            addi sp, sp, -24        ; sp = sp - 24 (스택 포인터 이동)

            ; 2. [레지스터 보존] Caller의 기존 레지스터 값들을 스택에 푸시(Save)
            sd   x5, 16(sp)         ; 임시 레지스터 x5의 기존 값 저장
            sd   x6, 8(sp)          ; 임시 레지스터 x6의 기존 값 저장
            sd   x20, 0(sp)         ; 저장 레지스터 x20(f)의 기존 값 저장

            ; 3. [본문 연산 수행] f = (g + h) - (i + j)
            add  x5, x10, x11       ; x5 = x10(g) + x11(h)
            add  x6, x12, x13       ; x6 = x12(i) + x13(j)
            sub  x20, x5, x6        ; x20(f) = x5 - x6

            ; 4. [반환값 설정] 결과 f를 반환값 전용 레지스터인 x10으로 복사
            addi x10, x20, 0        ; x10 = x20 + 0 (반환 레지스터 x10에 f 설정)

            ; 5. [레지스터 복원] 스택에서 원래 사용자의 레지스터 값들을 팝(Restore)
            ld   x20, 0(sp)         ; 스택 0(sp) 위치에서 x20 복구
            ld   x6, 8(sp)          ; 스택 8(sp) 위치에서 x6 복구
            ld   x5, 16(sp)         ; 스택 16(sp) 위치에서 x5 복구

            ; 6. [스택 해제 및 복귀]
            addi sp, sp, 24         ; sp = sp + 24 (스택 포인터 원위치)
            jalr x0, 0(x1)          ; 레지스터 x1(ra)에 저장된 복귀 주소로 복귀 점프
        ```

    * **비말단(Non-Leaf) 프로시저**: 내부에서 또 다른 함수를 부르는 함수
        * x1하나뿐 → 중첩 호출 시 반환 주소 `x1(return address)`이 지워지므로, **반드시 스택에 `x1`과 인자값을 저장한 후 복원**해야
        * **스택에 저장해야 하는 것2**
            * <span class="hl-yellow">반환 주소</span>
            * <span class="hl-yellow">호출 이후에도 필요한 모든 인수와 임시 변수</span>
        * ex. 재귀함수

            ```c
            long long int fact (long long int n) {
                if (n < 1) return 1;
                else return n * fact(n - 1);
            }
            ```

            ```nasm
            fact:
                ; 1. [스택 공간 확보] 복귀 주소(x1)와 인자 n(x10) 보존을 위해 16바이트 확보
                addi sp, sp, -16        ; sp = sp - 16

                ; 2. [주요 정보 저장] 나중에 나를 불렀던 곳으로 돌아갈 주소(x1)와 내 인자(x10) 저장
                sd   x1, 8(sp)          ; 복귀 주소 x1(ra)을 스택 8(sp)에 저장
                sd   x10, 0(sp)         ; 현재 호출의 인자 n(x10)을 스택 0(sp)에 저장

                ; 3. [기저 조건(Base Case) 검사] n < 1 인지 확인 (즉, n - 1 < 0 인지 검사)
                addi x5, x10, -1        ; x5 = n - 1
                bge  x5, x0, L1         ; 만약 x5 >= 0 (즉, n >= 1) 이면 재귀 호출 블록 L1으로 점프

                ; 4. [기저 조건 처리: n < 1 일 때] return 1
                addi x10, x0, 1         ; 반환값 레지스터 x10을 1로 설정
                addi sp, sp, 16         ; 스택 공간 16바이트 해제 (저장했던 값 복구 없이 팝)
                jalr x0, 0(x1)          ; 나를 호출한 곳으로 즉시 복귀

            L1:
                ; 5. [재귀 호출 준비: n >= 1 일 때] fact(n - 1) 호출
                addi x10, x10, -1       ; 인자 감소: x10 = n - 1
                jal  x1, fact           ; fact(n - 1) 재귀 호출! (x1 레지스터가 새로운 복귀 주소로 갱신됨)

                ; 6. [재귀 호출 완료 후 복원 과정]
                addi x6, x10, 0         ; 재귀 호출의 결과값 fact(n - 1)을 레지스터 x6으로 옮김
                ld   x10, 0(sp)         ; 스택에 보관해두었던 '원래 나의 인자 n'을 x10으로 복구
                ld   x1, 8(sp)          ; 스택에 보관해두었던 '원래 나의 복귀 주소'를 x1(ra)로 복구
                addi sp, sp, 16         ; 스택 프레임 해제 (포인터 복원)

                ; 7. [최종 연산 및 반환] return n * fact(n - 1)
                mul  x10, x10, x6       ; x10 = n * fact(n - 1) (x10 * x6)
                jalr x0, 0(x1)          ; 원래 호출자(Caller)에게로 복귀
            ```

5. **메모리 레이아웃**
    * **Text**: 기계어 코드 영역 (낮은 주소)
    * **Static Data**: 전역 변수 및 정적 데이터 영역
    * **Dynamic Data (Heap)**: 동적 할당 영역 (`malloc`, 주소가 위로 증가)
    * **Stack**: 함수 호출 시 지역 변수 및 저장 레지스터 보존 영역 (높은 주소에서 아래로 감소, `sp` 포인터 사용)

++)

* 유니코드: 32비트 문자 집합
* UTF-8, UTF-16: 가변 길이 인코딩

### 3. 바이트/하프워드/워드 연산

1. **데이터 크기별 load/store 명령어**
    * **Load (메모리 → 레지스터)**
        * `lb` (1바이트), `lh` (2바이트), `lw` (4바이트): 메모리에서 읽은 후 상위 비트를 **부호 확장 (Sign Extension)**
        * `lbu` (1바이트), `lhu` (2바이트), `lwu` (4바이트): 메모리에서 읽은 후 상위 비트를 **0으로 채움**
        * <span class="hl-yellow">명령어, 크기, 용도 표</span>

            | 명령어 | 이름 | 크기 | 용도 |
            | --- | --- | --- | --- |
            | lb/lbu | load byte | 1byte | char, ASCII |
            | lh/lhu | load half word | 2bytes | short, UTF-16(유니코드) |
            | lw/lwu | load word | 4bytes | int(32bits 정수) |
            | ld | load double word | 8bytes | long long, 포인터 |

    * **Store (레지스터 → 메모리 저장): 그냥 명령어에 s만 붙이면 됨**
        * `sb` (1바이트), `sh` (2바이트), `sw` (4바이트): 레지스터의 제일 오른쪽 8, 16, 32비트만 메모리에 저장

* **C 언어 문자열 복사 (`strcpy`)**
    * 1바이트 문자를 읽어오기 위해 `lbu`, 저장하기 위해 `sb`를 사용하며, 널 문자(`'\0' == 0`)를 만날 때까지 루프를 반복

### 4. 대용량 상수 및 주소 지정 방식

12비트 상수로도 안 되는 것 처리

1. **32비트 대용량 상수 생성 (`lui`)**
    * **`lui rd, constant`** (Load Upper Immediate): 20비트 상수를 레지스터 `rd`의 상위 비트 `[31:12]`로 복사하고, 하위 12비트는 0으로 채움
    * **32비트 상수 완성**: **`lui`** (상위 20비트 설정) + **`addi`** (하위 12비트 가산)
    * 명령어 type: U type

        |  |  |  |
        | --- | --- | --- |
        | imm[31:12] | rd[11:7] | opcode[6:0] |

2. **주소 지정 방식4**
    1. **즉치값 주소 지정 (Immediate Addressing)**: 피연산자가 명령어 내부 상수에 있음
    2. **레지스터 주소 지정**: 피연산자가 레지스터에 있음
    3. **베이스 주소 지정**: 레지스터 값 + 명령어 내 오프셋을 더해 메모리 주소 계산 (예: `64(x22)`)
    4. **PC-상대 주소 지정 (PC-relative Addressing)**: 현재 PC 값 + 명령어 내 오프셋을 더해 메모리 주소 계산(목적지 = PC + 오프셋) → 점프

3. <span class="hl-yellow">**RISC-V 6가지 명령어 형식**</span>

    | **U-type** | imm[31:12] | imm[31:12] | imm[31:12] | imm[31:12] | rd | opcode | **대용량 상위 상수 설정** (`lui`) |
    | **UJ-type** | imm[20, 10:1, 11, 19:12] | imm[20, 10:1, 11, 19:12] | imm[20, 10:1, 11, 19:12] | imm[20, 10:1, 11, 19:12] | rd | opcode | **무조건 점프** (`jal`) |

    1. R-형식(Register-Register Format)

        | --- | --- | --- | --- | --- | --- |
        | funct7(7) | rs2(5) | rs1(5) | funct3(3) | rd(5) | opcode(7) |

        * 필드 구성
            * `opcode` (7비트): 연산의 큰 분류(산술 연산)를 지정
            * `rd` (5비트): 연산 결과를 저장할 목적지 레지스터 번호
            * `funct3` & `funct7` : 덧셈/뺄셈/시프트 등 세부 연산 종류를 구별
            * `rs1` (5) & `rs2` (5): 연산에 사용할 첫 번째, 두 번째 소스 레지스터 번호
        * 레지스터 간의 산술 및 논리 연산 (`add`, `sub`, `and`, `or`, `sll`)할 때 씀

    2. I-형식(imm Format)

        | --- | --- | --- | --- | --- |
        | imm(12) | rs1(5) | funct3(3) | rd(5) | opcode(7) |

        * 필드 구성
            * `rs2` + `funct7` → 12비트 상수(`immediate`)
            * `rs1` (5비트): 소스 레지스터 번호
            * `immediate` (12비트): 상수 연산 → 상수 피연산자, 상수 앞에 괄호 있음 → 메모리 오프셋 값
        * 상수 피연산자 연산 (`addi`), 메모리 로드 명령어 (`ld`, `lw`, `lb`)할 때 쓰고+
        * 레지스터 간접 점프 (`jalr`): lui로 이동하려는 목적지 주소 상위 20비트 레지스터에 로드해 놓고 → 거기에 imm을 하위 12비트 오프셋으로 바로 더해서 32비트 목적지 주소 계산해서 바로 점프

    3. **S-형식(Store Format)**

        | --- | --- | --- | --- | --- | --- |
        | imm[11:5]\(7) | rs2(5) | rs1(5) | funct3(3) | imm[4:0]\(5) | opcode(7) |

        * 필드 구성
            * `rs2` (5): 기준 주소 레지스터 번호
            * `rs1` (5): 소스 레지스터 번호
            * `immediate` (12비트): 쪼개서 저장함(rs2, rs1을 디코더가 항상 같은 위치에서 읽게 하려고)
        * 메모리 저장 명령어 (`sd`, `sw`, `sb`)로 씀

    4. SB-형식**(Conditional Branch Format / B-Type)**
        * 구조가 S-형식이랑 동일하지만 상수를 다르게 쪼갬

        | --- | --- | --- | --- | --- | --- | --- | --- |
        | imm[12]\(1) | imm[10:5]\(6) | rs2(5) | rs1(5) | funct3(3) | imm[4:1]\(4) | imm[11]\(1) | opcode(7) |

        * PC-상대 주소 지정 방식으로만 사용함
        * 상수: 조건 분기 목적지 주소를 계산하는 오프셋
        * 명령어 자체가 기본적으로 4바이트 → 오프셋도 항상 짝수임(PC가 무조건 짝수니까) ⇒ immediate[0]은 무조건 0임 → 저장 안 함

            ⇒ 그래서 타깃 주소는 PC + 즉치값 * 2

        * 조건 분기 명령어 (`beq`, `bne`, `blt`, `bge`)에 씀

    5. **U-형식 (Upper Immediate Format)**

        | --- | --- | --- |
        | **imm[31:12]** **(20)** | rd(5) | opcode(7) |

        * 필드 구조:
            * 상위 20비트 → 대용량 상수에
            * 지정한 20비트 상수를 목적지 레지스터 `rd`의 상위 비트 `[31:12]`로 직접 로드
        * 주요 용도:
            * `lui`: rd 상위 20비트에 imm[31:12]를 복사하고, 하위 12비트는 0으로 채움 → 이후에 addi 써서 하위 12비트 완성
            * `auipc`: PC 상대 상위 주소 가산

    6. **UJ-형식 (Unconditional Jump Format / J-Type)**

        | --- | --- | --- | --- | --- | --- |
        | imm[20]\(1) | imm[10:1]\(10) | imm[11]\(1) | imm[19:12]\(8) | rd(5) | opcode(7) |

    * 필드 구조:
        * 20비트 공간을 오프셋 상수로 사용
        * `rd` : 반환 주소 저장
    * 주요 용도: 무조건 점프 및 링크 명령어 (`jal`)
