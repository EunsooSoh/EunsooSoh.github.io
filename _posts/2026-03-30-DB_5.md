- 논리적 데이터 모델 중 하나
- 하나의 개체에 관한 데이터 → 2차원 테이블 형태의 릴레이션 하나

1. 관계 데이터 모델
    1. 용어
        1. 속성: 열
        2. 투플: 행
        3. 도메인: 하나의 속성이 가질 수 있는 모든 값의 집합
        4. 차수: 하나의 릴레이션에 존재하는 속성의 총 개수
        5. 카디널리티: 투플의 총 개수
    2. 릴레이션의 구성
        - 스키마(릴레이션 내포): 릴레이션의 구조 (정적)
        - 인스턴스(릴레이션 외연): 어느 한 시점에 릴레이션에 있는 투플들의 집합(동적)
2. 릴레이션 특성
    1. 속성의 유일성: 각 속성들은 유일해야 함
    2. 속성의 무순서성
    3. 투플의 무순서성
    4. 속성의 원자성: 속성으로는 원자값만 사용할 수 있음
3. Key
    1. 특성:
        1. 유일성: 키에 해당하는 값들은 유일해야 함(=모든 투플은 서로 다른 키값을 가져야 함)
        2. 최소성: 꼭 필요한 속성들로만 키를 구성해야 함
    2. 종류:
        
        4모양
        
        슈퍼키(유일성 만족)
        
        → 후보키 (유일성, 최소성 만족)
        
        → 기본키/대체키
        
        외래키: 다른 릴레이션의 기본키를 참조하는 속성
        
        → 이름은 달라도 되지만 도메인은 같아야 함
        
4. 관계 데이터 모델 무결성 제약 조건
    1. 개체 무결성 제약
        
        : 기본키를 구성하는 모든 속성은 NULL을 가질 수 없음
        
    2. 참조 무결성 제약
        
        : 참조할 수 있는 값만 가질 수 있음. 단, 외래키는 NULL을 가질 수 있음
        
- 삭제:
    - 참조되는 쪽: 참조하는 것도 같이 지우든지, 기본값이나 NULL값으로 대체해야 함
    - 참조하는 쪽: 상관없음
