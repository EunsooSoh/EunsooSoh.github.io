1. 스레드 개념
    
    매 요청마다 fork()하면 너무 무겁기 때문에 같은 주소 공간을 공유하며 동시성을 달성하는 실행 단위
    
    - 동시성: 여러 작업이 시간에 걸쳐 실행
        - ex. OS가 시분할을 통해 동시에 진행되는 것처럼 보이게 하는 것(OS가 스레드 단위로 스케줄링)
        - 싱글 코어 기반
    - cf. 병렬성: 여러 작업이 동시에 실행
        - ex. 각 코어가 별도의 스레드를 동시에 진행하는 것
        - 데이터 병렬성: 같은 데이터 부분 집합을 여러 코어에 분배
        - 태스크 병렬성: 서로 다른 작업을 여러 코어에 분배
        - 멀티코어 기반
    - 멀티 스레드에서 자원의 공유, 독립
        - 공유: code, data, heap, open file entry
        - 독립: PC, stack, regs, TLS
            
            → stack 사이사이 guard page가 있고 넘어가면 SIGSEGV
            
2. 멀티스레드
    
    ```c
    #include <pthread.h>
    #include <stdio.h>
    
    typedef struct { 
        int from, to; 
        long result; 
    } Range;
    
    void *sum_range(void *arg) {
        Range *r = (Range *)arg;
        r->result = 0;
        for (int i = r->from; i <= r->to; i++)
            r->result += i;
        return NULL;
    }
    
    int main() {
        pthread_t t1, t2;
        Range r1={1,50,0}, r2={51,100,0};
        
        // 두 스레드를 생성하여 각각 1~50, 51~100 합산 수행
        pthread_create(&t1, NULL, sum_range, &r1);
        pthread_create(&t2, NULL, sum_range, &r2);
        
        // 작업이 끝날 때까지 대기 (join)
        pthread_join(t1, NULL);
        pthread_join(t2, NULL);
        
        printf("total=%ld\n", r1.result + r2.result); // 5050 출력
    }
    ```
    
    - 장점
        
        (1) 응답성: 한 스레드가 블록되어도 다른 스레드는 실행
        
        (2) 자원공유: 별도의 IPC 없이 메모리를 같이 사용
        
        (3) 경제성: 프로세스보다 생성, 문맥 교환 저렴
        
        |  | 프로세스 전환 | 스레드 전환 |
        | --- | --- | --- |
        | mode switch | O | O |
        | regs 저장, 복원 | O(PCB)에 | O(TCB에) |
        | MMU, TLB 전환 | O | X |
        | 캐시 미스 | O | 최소 |
        
        (4) 확장성: 멀티코어에서 병렬 실행 가능
        
    - amdahl 법칙
        
        speed up ≤ 1/{s - (1-s)/N} N은 직렬 비율, N은 코어 수
        
        - 직렬 부분이 생기는 이유
            - lock 경합: 임계 영역 진입 대기 → 직렬화
            - IO 대기
            - 데이터 의존
3. PCB, TCB
    
    
    | PCB | TCB |
    | --- | --- |
    | 같은 프로세스 내 모든 스레드가 공유 | 스레드마다 하나씩 가지고 있음
    PC, SP, regs, 스레드 상태 등 저장 ⇒ 스레드 복원 시 이거 저장 복원 |

    - 아무튼 PCB를 모든 스레드가 공유하기 때문에 하나 장애 생기면 나머지 다 죽음 → 안정성, 격리가 중요하면 멀티 프로세스
    - 현대 OS 사용자 스레드 - 커널 스레드 1:1 매핑
        - 커널이 각 스레드를 독립적인 단위로 인식하고 동일한 흐름으로 실행
        - 한 스레드 블로킹 되어도 다른 스레드는 별도의 커널 스레드로 계속 실행 가능
            
            cf. M:1 한 스레드 블로킹 되면 다른 스레드도 블로킹
            
4. Pthread
    - 스레드 라이브러리
        
        (1) POSIX pthreads (2) window threads (3) Java threads
        
    
    (1) 주요 API
    
    - 프로세스 죽으면 스레드도 죽지만, 만약 오래 사는 프로세스라면 join이나 detach로 빨리 정리해야 함 (join이나 detach하지 않으면 누수!)
    
    | pthread_create() | 스레드 생성 |
    | --- | --- |
    | pthread_join() | 종료 대기 → 안 하면 자원 누수 |
    | pthread_exit() | 스레드 종료 |
    | pthread_detach | 종료 후 운영체제가 자동 정리 |

    - 흐름: 분할 → 병렬 실행 → join → 결과 합산
    
    (2) TLS (Thread Local Storage)
    
    __thread 키워드 쓰면 전역 같아도 스레드별로 독립된 TLS 영역에 사본 만들어서 사용
    
    ```c
    static __thread int tsum = 5; 
    int total = 0; // 진정한 전역 변수 (모든 스레드가 공유)
    
    void *calcThread(void *param) {
        int n = atoi((char *)param);
        printf("init tsum=%d\n", tsum); // 각각 독립적으로 5에서 시작
        
        for (int i = 1; i <= n; i++)
            tsum += i; // TLS 변수 업데이트: 다른 스레드와 간섭 없음
            
        printf("after tsum=%d\n", tsum);
        total += tsum; // 전역 변수 업데이트: 공유 자원이므로 여기서 Race Condition 발생 가능!
        return NULL;
    }
    
    int main() {
        char *p[2] = {"100", "200"};
        pthread_t tid[2];
        
        for (int i = 0; i < 2; i++)
            pthread_create(&tid[i], NULL, calcThread, p[i]); // T1은 100까지, T2는 200까지
            
        for (int i = 0; i < 2; i++)
            pthread_join(tid[i], NULL);
            
        printf("total = %d\n", total);
    }
    ```
    
5. 멀티 스레드 문제
    
    (1) Race condition
    
    두 스레드가 공유변수인 counter에 대해서 원자적이지 않은 연산(++, —)할 때 3단계로 진행됨 → 중간에 값이 덮어씌워져서 값이 없어질 수 있음
    
    ```c
    volatile int counter = 0; // 공유 데이터
    
    void *worker(void *arg) {
        for (int i = 0; i < 1000000; i++)
            counter++; // BUG! (비원자적 연산: Load -> Add -> Store 과정에서 간섭 발생)
        return NULL;
    }
    
    int main() {
        pthread_t t1, t2;
        pthread_create(&t1, NULL, worker, NULL);
        pthread_create(&t2, NULL, worker, NULL);
        pthread_join(t1, NULL);
        pthread_join(t2, NULL);
        printf("counter = %d\n", counter); // 매번 비결정적인 결과 출력
    }
    ```
    
    - 임계 영역(Critical Section)
        
        : 공유 자원에 접근하는 코드 영역
        
    - 원자성
    
    (2) 데드락
    
    ```c
    pthread_mutex_t log_mtx = PTHREAD_MUTEX_INITIALIZER;
    
    void write_log(const char *msg) {
        pthread_mutex_lock(&log_mtx);
        printf("%s\n", msg);
        sleep(5); // T2가 이 락을 쥔 채로 멈춰있음
        pthread_mutex_unlock(&log_mtx);
    }
    
    void *worker(void *arg) {
        write_log("worker");
        return NULL;
    }
    
    int main() {
        pthread_t t2;
        pthread_create(&t2, NULL, worker, NULL);
        sleep(1); // T2가 락을 잡을 시간을 줌
        
        if (fork() == 0) { // T1이 fork() 호출
            // 자식 프로세스에는 T1만 존재하고, 락 상태는 '잠김'으로 복사됨!
            write_log("child"); // 락을 얻으려 하지만, 풀어줄 T2가 소멸되어 영원히 대기 (Deadlock)
            _exit(0);
        }
        // ...
    }
    ```
    
    멀티 스레드에서 fork() → 주소 공간은 복사하지만, 스레드는 fork() 호출한 그 스레드만 복사됨 → lock 풀어줄 스레드는 복사되지 않아서 자식의 유일한 스레드가 데드락에 빠짐
    
    ⇒ fork()하고 바로 exec()하면 락 상태 걍 날림
    
    - 시그널
        - 핸들러: 프로세스 전체가 공유
        - 받을 수 있는 스레드를 마스크로 설정 가능 (수신 여부 끄는 건 스레드 단위)
        
        ```c
        void *t1_func(void *arg) {
            sigset_t set;
            sigemptyset(&set);
            sigaddset(&set, SIGINT);
            // T1은 SIGINT(Ctrl+C) 시그널을 차단(Block)함
            pthread_sigmask(SIG_BLOCK, &set, NULL); 
            // ... work ...
        }
        
        void *t2_func(void *arg) {
            // 마스크를 설정하지 않음 -> SIGINT를 받을 수 있음 (unmasked)
            // ... work ...
        }
        
        int main() {
            pthread_t t1, t2;
            pthread_create(&t1, NULL, t1_func, NULL);
            pthread_create(&t2, NULL, t2_func, NULL);
        
            kill(getpid(), SIGINT);    // 프로세스 전체에 시그널 전송 -> 마스크가 안 된 T2가 받아서 처리
            pthread_kill(t1, SIGUSR1); // 특정 스레드(T1)를 콕 집어서 직접 시그널 전송
        }
        ```
        
        - pthread_sigmask(SIG_BLOCK, &set, NULL);
            - set에 있는 신호들을 차단 목록에 추가
        - pthread_create(&t1, NULL, t1_func, NULL);
            - &t1: 스레드 아이디 저장할 주소
            - t1_func: 스레드가 생성되자마자 실행될 함수
