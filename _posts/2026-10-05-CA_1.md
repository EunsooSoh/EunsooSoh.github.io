* 컴퓨터의 분류
    1. 개인용 컴퓨터: 범용 목적
    2. 서버 컴퓨터: 네트워크 기반 서비스 제공
    3. 슈퍼컴퓨터: 서버의 일종
    4. 임베디드 컴퓨터: 다른 기기나 시스템 내부의 구성 요소로 내장되어서 미리 정한 기능만 함

1. <span class="hl-yellow">**프로그램 성능의 이해**</span>

    | 구성 요소 | 성능에 미치는 영향 |
    | --- | --- |
    | 알고리즘 | 소스 프로그램 문장 수와 입출력 작업 수를 결정 |
    | 프로그래밍 언어, 컴파일러, 컴퓨터 구조 | 각 소스 프로그램 문장에 해당하는 기계어 명령어 수 결정 |
    | 프로세서와 메모리 시스템 | 명령어의 실행 속도 결정 |
    | 입출력 시스템(하드웨어 및 운영체제) | 입출력 작업의 실행 속도 결정 |

2. 컴퓨터 아키텍처 아이디어 7
    1. 설계를 단순화하는 추상화
    2. 자주 생기는 일을 빠르게
    3. 병렬성을 통한 성능 개선
    4. 파이프라이닝을 통한 성능 개선
    5. 예측을 통한 성능 개선
    6. 메모리 계층 구조
    7. 여유분을 이용한 신뢰도 개선

3. 프로그램 내부
    * 응용 소프트웨어
        * 시스템 소프트웨어(ex. 컴파일러, 운영체제)
            * 하드웨어

4. 프로그램 코드 수준
    1. 고급 언어: 생산성 높고, 이식성 제공
    2. 어셈블리 언어: 하드웨어 기계어 명령어를 사람이 읽을 수 있는 문자로 일대일 대응시킨 언어
    3. 기계어/하드웨어 표현

5. 컴퓨터 구성 요소
    1. 입출력 장치
        1. 인터페이스 장치
        2. 저장 장치
        3. 네트워크 어댑터
    2. 터치스크린(요즘은 보통 정전식)
    3. 디스플레이

        LCD 화면: frame buffer 값으로 밝기 표현

    4. 프로세서(CPU)
        1. 데이터패스(Datapath): 데이터에 대한 연산이 수행되는 장소
        2. 제어 장치: 데이터패스, 메모리 등의 동작 순서 제어
        3. 캐시 메모리(휘발성): 빠른 데이터 접근을 위해 CPU에 내장된, 작고 빠른 SRAM

6. 추상화
    * 저수준 세부사항 숨김
    * ISA
        * Instruction Set Architecture
        * HW↔SW IF
    * ABI
        * Application Binary Interface
        * ISA와 시스템 SW IF 결합

    ⇒ 기본 원리와 IF 세부사항 구현

7. 저장 장소
    1. 휘발성 → 전원이 꺼지면 명령어와 데이터가 사라짐

        ex. DRAM

    2. 비휘발성 → 전원이 꺼져도 데이터가 유지됨

        ex. HDD, SSD, CD-ROM, DVD

8. 네트워크
    * LAN
        * Local area network(근거리 통신망)
        * ex. 이더넷
    * WAN
        * Wide area network(광역 네트워크)
        * ex. 인터넷

    ++) 무선 네트워크 ex. 와이파이, 블루투스

9. 집적회로(Integrated Circuit)
    1. 물질 분류
        1. 양도체(=도체) ex. 구리, 알루미늄
        2. 반도체
            * ex. 실리콘
            * 회로에서 <span class="hl-yellow">스위치</span>(트랜지스터) 역할
            * 조건에 따라 도체가 되기도 함
        3. 절연체(=부도체) ex. 플라스틱, 유리
    2. 제조 과정
        1. Silicon ingot을 Slicer로 자름 → Blank wafers
        2. 여러 공정 거침 → Patterned wafers
        3. Wafer tester로 테스트 → Tested wafer
            * 이 과정에서 불량을 확인하고 제외시킴
        4. tested wafer를 dicer로 컴포넌트별로 자름 → dies(칩이라고도 함)
        5. die를 package에 붙임 → packaged dies
        6. Part tester로 packaged die를 테스트해서 불량 제외
    3. <span class="hl-yellow">수율: 웨이퍼당 정상 작동하는 die의 비율</span>

        $$\text{수율} = \frac{1}{\left(1+(\text{면적당 결함 수} \times \text{다이 면적})\right)^N}$$

        * <span class="hl-yellow">면적과 결함률은 비선형적</span>
            * 웨이퍼 비용, 웨이퍼 면적은 고정인데
            * 결함률(N)은 제조 공정에 의해 결정되고, 다이 면적도 회로 설계에 의해 결정됨
