1. 암스트롱 추론 규칙
    1. Reflexive: Y가 X에 포함(Y가 X의 부분 집합) ⇒ X → Y
    2. 부가성: X → Y ⇒ AX → AY
    3. 이행성: X → Y and Y → Z ⇒ X → Z
    4. 분해: X → YZ ⇒ X → Y and X → Z
    5. union: 그냥 분해의 반대
    6. 의사 이행성: X → Y and WY → Z ⇒ WX → Z
    
    *** 그리고 너무 당연하지만 X → Y이면 X가 Y를 결정한다 = Y에 대응되는 X는 하나뿐이다 ⇒ Y가 들어가는 모든 자리에 X 들어갈 수 있음
    
2. minimal set 구하는 방법
    
    step 1. 우변이 단일 속성을 갖게 함
    
    step 2. 좌변에서 불필요한 속성 줄임
    
    step 3. 지워도 꼬리 물고 같은 결과 낼 수 있는 규칙 삭제
