1. 등장 배경: 파일 시스템의 문제점
    1. 데이터 중복성
    2. 데이터 종속성: 응용 프로그램이 데이터에 종속적임
    
    ++ c. 보안 회복, 동시 공유 기능 부족 d. 응용 프로그램 개발이 힘듦
    
2. 정의: 데이터베이스에 통합 저장하고 관리하는 시스템
    - 기능:
        1. 정의
        2. 조작: 데이터 삽입, 삭제, 수정, 검색
        3. 제어: 데이터 정확, 안전 유지
3. DBMS 장단점
    
    (+)
    
    - a~d 해결
    - 데이터 무결성 유지
    - 표준화 기능
    
    (-)
    
    - 비용
    - 백업, 회복 복잡
    - 중앙 집중 단점
4. 발전 과정
    
    (1) 네트워크(그래프), 계층(트리)
    
    (2) 관계형
    
    (3) 객체 지향, 객체 관계(객체 지향 + 관계형)
    
    (4) NoSQL(비정형), NewSQL(관계 + NoSQL)
