## 1. 메모리의 종류와 계층 (프로세서와 가까운 순서대로)

* BRAM (Block RAM)
    - FPGA 칩 내부에 기본적으로 분산되어 박혀있는 메모리 블록.
    - 용량은 작지만(수 KB ~ 수 MB 수준), 칩 내부에 있어 속도가 매우 빠르고 지연 시간이 거의 없음.
    - 주로 FIFO 버퍼, 작은 캐시, 룩업 테이블(LUT) 용도로 쓰임.


* URAM (UltraRAM)
    - 최신 고성능 FPGA(Xilinx UltraScale+ 등)에 들어있는 칩 내부 메모리.
    - BRAM보다 집적도가 높아 더 큰 용량을 제공. 큰 비디오 버퍼나 딥러닝 모델의 파라미터를 저장할 때 BRAM의 부족한 용량을 채워줌.


* HBM (High Bandwidth Memory)
    - 칩 내부(die)는 아니지만, FPGA 칩과 같은 패키지 안에 여러 겹으로 쌓아 올려 연결한 차세대 메모리.
    - 일반 DDR보다 용량도 크고, 대역폭이 매우 넓어서(TB/s 수준) 초고속 통신이나 인공지능 연산에 필수적.


* DDR3 / DDR4
    - PC나 서버에 꽂는 일반적인 외부 메모리(RAM).
    - 용량은 가장 크지만(수 GB 이상), 칩 외부에 있어 속도가 상대적으로 느림. 대규모 데이터를 임시로 보관할 때 사용.



| 종류 | 위치 | 속도/대역폭 | 용량 | 주 용도 |
| --- | --- | --- | --- | --- |
| **BRAM** | 칩 내부 | 매우 빠름 | 작음 | 고속 버퍼, 캐시 |
| **URAM** | 칩 내부 | 빠름 | 중간 | 대용량 버퍼 |
| **HBM** | 칩 패키지 내부 | 엄청나게 넓음 | 큼 | AI, 초고속 네트워킹 |
| **DDR4** | 칩 외부 | 보통 | 매우 큼 | 메인 메모리, 대용량 저장 |

## 2. 외부 메모리 제어 (DDR과 통신하기)

FPGA가 외부에 있는 DDR 메모리를 직접 제어하려면 복잡한 신호를 타이밍에 맞춰 보내야 함. 아래는 이를 도와주는 도구와 개념들.

* MIG (Memory Interface Generator)
    - Xilinx에서 제공하는 IP(소프트웨어 블록).
    - 사용자가 복잡한 DDR 메모리의 전기적 신호와 타이밍을 직접 코딩하지 않아도 되도록, FPGA 로직과 외부 메모리 사이를 연결해 주는 컨트롤러 역할.


* Bank
    - 데이터를 효율적으로 찾기 위해 메모리를 나눈 단위. 
    - 한 뱅크에서 데이터를 찾는 동안 다른 뱅크를 미리 준비시킬 수 있음 -> 속도 높임.


* DQ (Data Query / Data Pin)
    - 메모리와 칩 사이에 실제 데이터(0, 1)가 오가는 물리적인 핀 또는 선. 
    - ex. "DQ가 64비트다" = 한 번에 64개의 차선으로 데이터가 이동한다.


* Burst Length (BL)
    - 메모리에 특정 위치 데이터 요청했을 때, 해당 위치 하나만 딱 주는 게 아니라 연속된 데이터를 한 묶음으로 쏟아내는 길이. 
    - 보통 BL8 (8개를 한 번에 보냄)을 많이 씀. 
    - 한 번의 요청으로 많은 데이터를 가져와 효율 높임.

## 3. 메모리 타이밍

* tCK (Clock Tick / Clock Period)
    - 메모리가 동작하는 기준이 되는 클럭 주파수의 한 사이클(주기) 시간. 
    - 예를 들어 1GHz로 동작하는 메모리라면 tCK는 1ns(나노초). 
    - 모든 동작은 이 tCK를 기준으로 박자를 맞춤.


* CAS Latency (CL)
    - Column Address Strobe Latency.
    - CPU(또는 FPGA)가 메모리에게 특정 주소 데이터를 달라는 명령을 내린 순간부터, 첫 번째 데이터가 DQ 핀을 통해 밖으로 나올 때까지 걸리는 클럭 수(대기 시간). 
    - 이 숫자가 작을수록 응답 속도가 빠름.
