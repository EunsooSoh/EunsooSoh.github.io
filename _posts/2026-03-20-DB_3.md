1. 정의: 데이터 저장, 관리해서 정보를 생성하는 시스템
2. DB 구조
    1. 기본 용어
        - 스키마: 데이터베이스의 구조
        - 인스턴스: 스키마에 따라 실제 저장된 값
    2. 3단계 구조 ⇒ 데이터 독립성 목적!! (데이터 독립성: 아래에 있는 거 수정해도 전체를 뜯어고치는 게 아니라 매핑 정보만 수정함)
        
        (1) 외부 단계(사용자 관점) —— 외부 스키마(여러 개 존재 가능)
        
        ---
        
        응용 인터페이스(논리적 데이터 독립성)
        
        ---
        
        (2) 개념 단계(전체 조직 관점) —— 개념 스키마(하나만 존재 가능)
        
        ---
        
        저장 인터페이스(물리적 데이터 독립성)
        
        ---
        
        (3) 내부 단계(저장장치 관점) —— 내부 스키마(하나만 존재 가능)
        
    3. 예시
        1. 데이터 사전
            - 사용자 접근은 가능하지만 검색만 가능
            - 메타데이터를 유지하는 시스템 DB
        2. 데이터 디렉터리
            - 사용자 접근 불가
            - 데이터 사전에 있는 데이터에 접근하기 위해 필요한 위치 정보를 저장하는 시스템 DB
        3. 사용자 데이터베이스
            - 일반 DB
3. DB 사용자 (목적에 따라 분류)
    1. DBA(데이터베이스 관리자)
        - 데이터 정의어, 제어어 사용
        - 당연하지만 DB 운영, 관리
    2. 최종 사용자
        - 데이터 조작어 사용
        - 캐주얼 사용자, 초보 사용자
    3. 응용 프로그래머
        - 데이터 조작어 사용
4. 데이터 언어(사용자↔DBMS)
    1. 데이터 정의어(DDL): 데이터의 구조 정의(=스키마 정의)
    2. 데이터 조작어(DML): 데이터를 처리
        1. 절차적 조작어: 어떤 데이터를 원하고, 어떻게 처리하는지
        2. 비절차적 조작어: 원하는 데이터 명시만
    3. 데이터 제어어(DCL): 규칙, 기법 정의 → 무결성, 보안, 장애 회복, 동시성 제어
5. DBMS 구성
    - 질의 처리기: 사용자의 데이터 요청문 처리
    - 저장 데이터 관리자: 데이터 사전, 데이터베이스 관리, 접근
