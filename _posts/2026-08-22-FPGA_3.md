양자화 하는 이유: FPGA 내부의 한정된 자원(BRAM, DSP)으로도 무거운 딥러닝 모델의 연산을 효율적으로 가속하려고

## 1. 양자화 시기

* PTQ (Post-Training Quantization)
    - 훈련 후 양자화. 
    - 모델을 원래의 고정밀도(실수형, FP32)로 끝까지 다 학습시킨 다음, 마지막에 데이터 타입만 강제로 정수(INT8)로 변환하는 방식.
    - 빠르고 간편하지만, 갑자기 데이터를 압축하다 보니 모델의 Accuracy가 떨어질 위험이 있음.


* QAT (Quantization-Aware Training)
    - 양자화 인지 훈련. 
    - 학습 과정 자체에 정수로 압축하는 오차를 미리 반영하여(시뮬레이션하며) 학습하는 방식.
    - 과정이 복잡하고 시간이 오래 걸리지만, 양자화로 인한 정확도 손실을 하드웨어가 견딜 수 있도록 훈련되기 때문에 성능 유지에 유리.



---

## 2. 데이터 포맷

* INT8 / INT4 (8-bit / 4-bit Integer)
    - INT8: 데이터를 -128부터 127까지 총 256개로 표현. 성능 하락을 최소화하면서도 메모리를 1/4로 줄일 수 있어 현재 AI 추론 가속기에서 가장 표준적으로 쓰임.
    - INT4: 데이터를 16개로 표현. 훨씬 빠르고 가볍지만 정확도를 유지하기가 매우 어려움 -> LLM처럼 극단적으로 메모리를 아껴야 할 때 제한적으로 사용.


* Q15 Fixed-point (고정소수점)
    - 총 16비트(1개의 부호 비트 + 15개의 소수부 비트)로 구성.
    - 데이터가 항상 -1.0과 1.0(정확히는 0.9999...) 사이에 있다고 가정. 
    - 소수점이 움직이지 않음 -> 복잡한 부동소수점 연산기 없이 단순한 정수 곱셈기만으로도 소수점 연산을 정확하게 흉내 낼 수 있음.



---

## 3. 실수 -> 정수 변환 방식

* Scale
    - 정수 1이 바뀔 때, 실제 실수로는 얼마만큼 변하는지를 나타내는 비율(Step size).
    - ex. 스케일이 0.1이면 하드웨어 안의 정수 5는 실제 실수 0.5.


* Zero-point
    - 데이터의 기준점을 맞춰주는 역할. 
    - 실수 0.0이 정수에 매핑되는 위치.



* 역양자화(Dequantization) 공식
    - 하드웨어(PL 영역)에서 정수로 계산한 결과를 실수로 되돌릴 때 다음 공식을 씀.

    $Real = Scale \times (Quantized - Zero_point)$
