: 원하는 데이터를 얻기 위해 릴레이션에 필요한 질의를 수행

1. 관계 대수
    
    : 릴레이션의 데이터 처리 과정을 순서대로 기술하는 절차 언어
    
    - 피연산자와 연산 결과 모두 **릴레이션**이라는 특성: 폐쇄특성
    - 연산자
        1. 일반 집합 연산자
            
            ※ 합병 가능 조건(1~3) → 카티션 프로덕트는 합병 가능 조건 필요 없음!
            
            (1) 차수가 같아야 함
            
            (2) 속성들의 도메인이 같아야 함
            
            - 합집합 → 차수 = 차수1 = 차수2, 카디널리티 ≤ 카1 + 카2
            - 교집합 → 차수 = 차수1 = 차수2, 카디널리티 ≤ 카1, 카2
            - 차집합 → 차수 = 차수1 = 차수2, 카디널리티 ≤ 카1 or 카2(아무튼 왼쪽에 있는 것 이하)
            - 카티션 프로덕트: 두 릴레이션의 각 투플을 모두 연결
        2. 순수 관계 연산자
            1. $\sigma_{조건}$ 셀렉트_조건: 조건을 만족하는 투플 반환(수평적 연산자)
                - 비교 연산자, 논리 연산자 사용 가능
            2. $\pi_{속성리스트}$ 프로젝트_속성리스트: 속성리스트에 해당하는 열을 반환
            3. 조인
                - 세타 조인
                - 동등 조인
                - 자연 조인: 동등 조인 결과에서 조인 속성이 한 번만 드러나게
            4. 디비전 R÷S: S의 모든 투플과 관련 있는 R의 투플들을 그 속성 제외하고 반환
        3. 확장 관계 대수 연산자 - 조인
            1. 세미 조인(R 연산 S): S를 R과 S의 조인 속성으로 셀렉트하고, 그 결과를 R과 자연 조인
            2. 외부 조인: 짝대기가 있는 쪽에 있는 모든 투플이 들어가게 조인
                - 왼쪽 외부 조인
                - 오른쪽 외부 조인
                - 완전 외부 조인
2. 관계 해석
    
    : 처리를 원하는 데이터가 무엇인지만 기술하는 비절차적 언어
    
    - 프레디킷 해석 기반
    - 종류:
        - 투플 관계 해석
        - 도메인 관계 해석
