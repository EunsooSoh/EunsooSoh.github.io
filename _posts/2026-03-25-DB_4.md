1. 데이터 모델링과 데이터 모델
    - 현실 세계 —추상화(개념적 모델링)→ 개념세계—논리적 모델링→ 컴퓨터세계
    - 데이터 모델: 데이터 모델링의 결과물을 표현
        
        구성:
        
        - 연산
        - 데이터 구조
        - 제약조건
2. 개체 관계 모델
    
    : 개체 간 관계를 표현하는 모델(개념적 모델 중 하나)
    
    - 핵심 요소
        1. 개체: 저장할 가치가 있는 중요 데이터를 가지고 있는 것
        2. 속성
            1. 값의 개수
                - 다중값
                - 단일값
            2. 의미 분해 가능 여부
                - 단순 속성
                - 복합 속성
            3. 유도 속성: 따로 저장하지 않고 다른 속성으로부터 계산해서 나올 수 있는 속성
        3. 관계
            
            유형 - 4기준으로 나눌 수 있음
            
            1. 참여 타입 수 기준: 이항 관계, …, 순환관계
            2. 종속성: 약한 관계, 강한 관계
            3. 필참여부: 필수 참여
            4. 매핑 카디널리티(각 개체 인스턴스가 연관성을 맺고 있는 상대 인스턴스 수) 기준
3. 논리적 데이터 모델
    
    : ERD를 DB에 저장할 논리적 도구로 표현
    
    - 종류 3가지
        - 관계 데이터 모델: 2차원 테이블 형태
        - 계층 데이터 모델: 1:n → n:m 직접적으로 표현할 수 없음, 트리
        - 네트워크 데이터 모델: 1:n → n:m 직접적으로 표현할 수 없음, 그래프
