1. 뷰: 기본 테이블 기반으로 만들어진, 논리적으로만 존재하는 가상 테이블
    - SQL
        1. 생성
            
            ```sql
            CREATE VIEW 뷰이름[(속성리스트)]
            AS SELECT 속성리스트
            [WITH CHECK OPTION]; # -> 조작할 때 정의 조건 위반하는 데이터 처리 거부
            ```
            
        2. 삭제
            
            ```sql
            DROP VIEW 뷰이름;
            ```
            
            - 기반이 되는 테이블에 영향 없음(삭제 안 됨)
            - 삭제할 뷰를 참조하는 제약조건이 있으면 삭제 안 됨
        3. 활용(검색, 조작)
            - 검색 SELECT
            - 조작 ⇒ 기본 테이블 변경
                - INSERT
                    
                    ```sql
                    INSERT 
                    INTO 뷰이름 
                    VALUES (값1, 값2, ...);
                    ```
                    
                - UPDATE
                    
                    ```sql
                    UPDATE 뷰이름
                    SET 속성이름1=값1, 속성이름2=값2, ...
                    [WHERE 조건]; # 조건을 만족하는 것만 위와 같이 수정
                    ```
                    
                - DELETE
                    
                    ```sql
                    DELETE 
                    FROM 뷰이름
                    [WHERE 조건]; # 조건을 만족하는 데이터를 지움
                    ```
                    
        - 뷰로 수정 불가한 경우 3가지: "뷰가 기본 테이블의 어떤 행과 일대일로 매칭되는지 알 수 없는 경우"
            1. 기본키나 not null 속성을 포함하지 않는 뷰
                
                → 무조건 있어야 하는 정보를 대충 null로 채울 수도 없어서 INSERT 불가
                
            2. 집계함수로 새로 계산된 내용, DISTINCT, GROUP BY 절을 포함
                
                → 원본 테이블의 어떤 행을 수정해야 하는지 몰라서 불가
                
            3. 여러 테이블을 조인한 경우
                
                → 출처가 섞여 있어서 마찬가지로 어떤 행을 수정해야 하는지 모름
                
    - 장점 3가지
        - 질의문 단순화
        - 데이터 보안: 사용자별 허용된 뷰의 데이터만 확인할 수 있음
        - 관리 편의: 사용자는 제공된 뷰만 신경쓰면 됨
2. 삽입 SQL: 응용 프로그램 안에 삽입해서 사용하는 SQL
    - 앞에 항상 붙이는 것: EXEC SQL
    - 일반 변수 앞에: 콜론(:)으로 DB 속성과 구분
    - 커서: SELECT로 반환되는 여러 행을 한 번에 하나씩 가리키는 포인터 역할
    - 처리 과정 4단계
        1. 선언 DECLARE
            
            : 커서의 이름과 select문 연결
            
        2. 실행 OPEN
            
            : 커서에 연결된 select문을 실행 ⇒ 결과 테이블 생성됨
            
        3. 이동, 추출 FETCH
            
            : 커서를 다음 행으로 이동시키고, 해당 행의 속성값을 프로그램 변수에 저장
            
        4. 종료 CLOSE
            
            : 커서 사용 종료
