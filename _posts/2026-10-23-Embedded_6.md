### Part 1. 센서와 액추에이터의 개념 및 주요 파라미터

#### 1. 정의 및 핵심 역할

* **센서 (Sensor)**: 물리량 → 전기 신호
* **액추에이터 (Actuator)**: 전기 신호 → 물리적 동작 수행
* **임베디드 제어 루프**: 감지 ➔ MCU(판단) ➔ 제어

#### 2. 센서

* **아날로그 센서**: 출력이 아날로그 → MCU가 읽기 위해 **ADC**(Analog-to-Digital Converter)가 필요
* **디지털 센서**: 센서 내부에 ADC있음 → 출력이 디지털 → 프로토콜(ex. I2C, SPI)로 직접 MCU와 통신
* 특성
    * **Rate (측정 빈도)**: 단위 시간당 데이터 수집 횟수
    * **Sensitivity (감도)**: 물리량 1단위 변화 시 출력 신호의 변화량
    * **Offset / Bias**: 입력이 0일 때 발생하는 초기 출력값
    * **Dynamic Range**: 측정 가능한 최대/최소 물리량 비 및 정밀도 비
    * **Noise**
    * **Nonlinearity**: 입출력이 직선 관계에서 벗어나는 왜곡 정도

### Part 3. 양자화 (Quantization) & ADC (Analog-to-Digital Converter)

#### 1. 양자화 개념 및 정밀도 (Precision)

* **양자화**: 연속적인 아날로그 신호를 n-비트 *(2^n개 단계)* 이산 값으로 매핑하는 과정
* **정밀도 (p)**: 센서가 구별할 수 있는 두 값 사이의 최소 차이 **p = (H - L) / 2^n**
    * H: 센서 입력 상한
    * L: 센서 입력 하한

    ⇒ 양자화 비트 수 증가 → 정밀도 폭↓(촘촘해지니까) → 양자화 오차 감소
* **동적 범위 (D_dB)**: **D = (H - L) / p = 2^n**
* 추가) ON/OFF 판단은 1비트 양자화해도 됨
* **크기축 이산화**

### Part 4. 샘플링 (Sampling)

#### 1. 샘플링 (Sampling) 정의

* **샘플링**: 시간 축의 이산화
    * 연속 시간 신호 x(t)를 일정 간격 T(샘플링 주기)마다 측정하여 이산 신호 s[n] = x(nT)로 변환
* **샘플링 주파수 (R = 1/T)**: 초당 샘플링 횟수 (Hz).
* **시간축 이산화**

⇒ 신호의 디지털화는 양자화 + 샘플링

#### 2. Aliasing

* **정의**: 샘플링 주파수가 너무 낮을 때, 고주파 신호가 샘플링 후 저주파 신호로 위장/접혀서 동일한 이산 신호로 관측되는 왜곡 현상
* 판단 방법: 샘플링 주파수 R이 **R ≥ 2 · f_max**을 만족하지 않음 → aliasing 발생
* 보이는 주파수:

$$\mathbf{f_{\text{alias}} = \lvert f - k \cdot R \rvert \quad (0 \le f_{\text{alias}} \le R/2)}$$

#### 3. Nyquist-Shannon 샘플링 정리

* **정리**: 원래 신호를 완벽히 복원하려면 샘플링 주파수 R이 **R ≥ 2 · f_max** 조건을 만족해야
* Anti-Aliasing Filter: Nyquist 조건 위반을 막기 위해 ADC 변환 직전 단계에서 f_max 이상의 고주파 성분을 차단하는 Low Pass Filter
* **임베디드 전력 Trade-off**:
    * 샘플링 주파수↑ 전력 소모, 데이터 처리량, 메모리 사용량↑
    * MCU의 Sleep 모드+타이머 인터럽트

        → DMA, ADC만 이용해서 데이터 SRAM에 옮기고, 타이머로 주기적으로 CPU가 깨서 데이터 처리

### Part 5. 신호 조절

#### 1. 고조파 왜곡

* **고조파 왜곡 (Harmonic Distortion)**: 시스템의 비선형성 → 입력 주파수 ω_0의 정수배 주파수 성분 추가 생성되는 현상

#### 2. 신호 조절 4

* 센서의 raw 신호를 ADC가 정확히 읽을 수 있도록 변환 전단에서 처리함:
    1. 증폭 (Amplification): OP-AMP를 이용해 약한 신호 → ADC 입력 범위로
    2. 필터링 (Filtering): 노이즈 제거
    3. 레벨 시프트 (Level Shifting): 음의 전압을 0 ~ 3.3V 양의 범위로 이동
    4. **Anti-Aliasing Filter**: 고주파 에일리어싱 차단 (2f_max 이상 성분 제거)

#### 3. C 언어 디지털 필터 구현

* **이동 평균 필터 (Moving Average Filter)**: 최근 N개 수집 값의 평균
    * 단점: N이 클수록 급격한 변화에 더 느리게 반응함
* **지수 가중 이동 평균 필터 (EMA)**:
    * y[n] = α · x[n] + (1 - α) · y[n-1] (0 < α ≤ 1, 직전값 가중치)
    * 이전 출력값 1개만 기억하면 되므로 메모리 사용량이 극히 적음
