### 자료형

- 종류
    - 숫자
    - 문자열
        - 특이한 점(C와 다른 점)
            - 문자열 곱하기 가능
            ```python
            print('문자열'*3)
            ```
            => 결과: 문자열문자열문자열 
            - 작은 따옴표 가능
                - 단, 문자열 안에 작은 따옴표가 있는 경우에는 큰 따옴표 써야 함
    - boolean
        - 특이한 점(C와 다른 점)
            - not 연산자
            ```python
            print(not (5>10))
            ```
            => 결과: True
    - 변수
        - 특이한 점(C와 다른 점)
            - 정의 시 자료형 명시하지 않아도 됨
            ```python
            name = '나요'
            age = 22
            is_male = False
            ```
        - '+'로 연결할 때
            - 만약에 string이 아닌 게 섞여 있으면 TypeError 발생
            ```python
            me = '짱'
            age = 22
            print('나는' + me + '이고, '+ str(age) + '살이에요.') # string 아닌 건 이런 식으로 형변환 해줘야 함
            ```
            => 결과: 나는 짱이고, 22살이에요.
            - 형변환 관련: 숫자로 이루어진 문자열을 float(), int()로 형변환할 수 있음
            - type() 으로 데이터의 자료형 확인 가능
                ```python
                print(type(3))
                print(type(str(3)))
                ```
                => 결과: 
                ```plain text
                <class 'int'>
                <class 'str'>
                ```
        - ','로 연결할 때
            ```python
            me = '짱'
            age = 22
            print('나는', me, '이고, ', str(age), '살이에요.') # 형 변환 필요 X
            ```
    - 주석
        - 여러 줄 작성 시 """와 """ 사이에 넣으면 됨


### 연산자

- 특이한 점(C와 다른 점)
    - A**B: A^B
    - A/B : A를 B로 나눈 값(실수)
    - A//B: A를 B로 나눈 몫(정수)
    - 비교 연산자 연달아 사용 가능
        ```python
        print(4>5>3)
        ```
        => 결과 False
    - 논리 연산자가 기호가 아님
        - and, or, not
